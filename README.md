# 早押しクイズ

学校で使う、オンライン参加の早押しクイズの Android アプリ(Flutter)です。ルームは1つで、進行(出題・早押しの判定・採点)はサーバーが自動で行い、解答は4択です。

このリポジトリにあるのはアプリだけです。サーバーは先生が別に用意していて、アプリは起動時に指定した接続先につながります。

## 必要なもの

- Flutter 3.41 以降(Dart 3.11 以降)
- Android Studio と、そのエミュレーター
- サーバーの接続先(`wss://` で始まり `/ws` で終わる URL。先生から伝えられます)

## 動かし方(Android Studio)

1. このリポジトリを clone し、Android Studio でフォルダーを開きます。
2. ターミナルで `flutter pub get` を実行します。
3. ツールバーの `main.dart` を押して **Edit Configurations...** を開き、**Additional run args** に次の1行を入れます。
   ```
   --dart-define=SERVER_URL=<サーバーの接続先>
   ```
4. エミュレーターを選び、緑の ▶(Run)を押します。初回のビルドは数分かかります。

コマンドで起動する場合は次のとおりです。

```bash
flutter run --dart-define=SERVER_URL=<サーバーの接続先>
```

接続先を指定しないと、同じ PC で動いている開発用サーバー(`ws://10.0.2.2:8787/ws`)を探しに行きます。

Android Studio が「プロジェクトを移行しますか」「Gradle を更新しますか」と聞いてきても、受け入れないでください。Flutter 3.41 でビルドできなくなることがあります。

## 使い方

### 生徒

1. アプリを開き、名前(12文字まで)を入れて「参加する」を押します。
2. 先生が開始すると問題文が1文字ずつ出ます。分かったら「早押し!」を押します。
3. 最初に押した人にだけ4択が出るので、10秒以内に答えます。
4. 正解で+1点、不正解は−1点です(押したのに時間内に答えなかった場合も−1点)。不正解だとその問題はお休みになり、ほかの人が早押しを続けます。

### 先生

クイズの開始は、サーバーの管理画面(PC のブラウザ)からでも、アプリの先生用画面からでもできます。アプリから行う場合は次のとおりです。

1. トップ画面の「先生用」を押し、暗証番号を入れます。
2. 問題セットを選んで「開始」を押します。セットからランダムに最大10問が出題されます。
3. ゲーム中は全員の得点が表示されます。「中止」で待機画面に戻せます。
4. 参加者名の横の × で1人を退出させられます。「全員を退出させる」は次のクラスに入れ替えるときに使います。

## うまくいかないとき

- **「サーバーに接続できません」と出る**: 接続先の指定が抜けているか、打ち間違いです。直したあとは、ホットリロードではなく、いったん止めてから起動し直します。
- **`flutter pub get` がバージョンのエラーで止まる**: Flutter が 3.41 より古い可能性があります。`flutter --version` で確認してください。
- **初回のビルドが進まない**: Gradle や Android SDK をダウンロードしています。ネットワークの制限で止まっていないか確認してください。
